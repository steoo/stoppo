# Stoppo

A mobile-first sliding puzzle on a transit map. Bring Stoppo home.

## Rules

- The board is a transit map. Stations are joined by colored lines.
- Every car has a color, and it can only ride a line of **its own color**.
- A move takes one car one stop along its line, and only into an **empty** station.
- Get **Stoppo** (the car with eyes) to the **ringed station**.

## Play

There is no build step. Serve the folder over HTTP, since ES modules don't load from `file://`:

```sh
npx serve .            # or: python3 -m http.server
```

Then open the printed URL on your phone or in the browser's mobile emulator.

Controls: drag a car along its line, or tap it and then tap a highlighted station. **Undo**, **Reset**, **Hint** and **Solve** sit in the bottom bar. Hint shows the next move from the current position; Solve plays the whole solution (a testing aid). Open a specific level with `?level=N`.
Progress and best scores are saved in `localStorage`.

## Project layout

| Path | Purpose |
| --- | --- |
| `index.html`, `style.css`, `icon.svg` | App shell, mobile layout and icon |
| `js/engine.js` | Rules, move generation and a BFS solver (shared with the tools) |
| `js/app.js` | SVG rendering, input and UI |
| `js/levels.js` | Level data, generated by `tools/build-levels.mjs` |
| `tools/build-levels.mjs` | Level source; rebuilds `js/levels.js` and checks each level's par with the solver |
| `tools/generate.mjs` | Random level generator (no longer used; overwrites `js/levels.js`) |

### Level format

```js
{
  name: "Level 1",
  par: 5,                         // optimal move count
  nodes: [[x, y], ...],           // station grid positions
  edges: [[a, b, color], ...],    // track between stations a and b
  cars: [[node, color], ...],     // starting cars
  target: { car: 0, node: 7 }     // cars[0] must reach station 7
}
```

Colors are indices into `COLORS` in `js/engine.js`. An edge pair may appear twice with different colors (parallel tracks).

The current levels are placeholders for development and will be replaced by original Stoppo levels before launch. After editing `tools/build-levels.mjs`, rebuild with `node tools/build-levels.mjs`; it fails if any level's optimal solution differs from its par.
