# Stoppo

A mobile-first sliding puzzle on a transit map. Bring Stoppo home.

## Rules

- The board is a transit map. Stations are joined by colored lines.
- Every car has a color, and it can only ride a line of **its own color**.
- A move takes one car one stop along its line, and only into an **empty** station.
- Get **Stoppo** (the car with eyes) to the **ringed station**.

## Play

There is no build step. Serve the `web/` folder over HTTP, since ES modules don't load from `file://`:

```sh
npm run serve          # or: python3 -m http.server -d web
```

Then open the printed URL on your phone or in the browser's mobile emulator.

## iPhone and iPad

The app ships natively through [Capacitor](https://capacitorjs.com). It needs Xcode with the iOS platform installed.

```sh
npm install
npm run ios            # copies web/ into ios/ and opens Xcode
```

In Xcode, pick a simulator or your device and press Run. After changing anything in `web/`, run `npx cap sync` again. Android can be added later with `npm install @capacitor/android && npx cap add android`.

Controls: drag a car along its line, tap an empty station to move the only car that can reach it, or tap a car and then a highlighted station. **Undo**, **Reset**, **Hint** and **Solve** sit in the bottom bar. Hint shows the next move from the current position; Solve plays the whole solution (a testing aid). Open a specific level with `?level=N`.
Progress and best scores are saved on the device; in the iOS app they're also kept in native storage and synced across the player's devices through iCloud.

## Project layout

| Path | Purpose |
| --- | --- |
| `web/` | The app: `index.html`, `style.css`, `icon.svg`, `fonts/`, `js/` |
| `ios/` | Native iPhone/iPad project (Capacitor) |
| `assets/` | App icon and splash sources |
| `web/js/engine.js` | Rules, move generation and a BFS solver (shared with the tools) |
| `web/js/app.js` | SVG rendering, input and UI |
| `web/js/levels.js` | Level data, generated by `tools/build-levels.mjs` |
| `tools/build-levels.mjs` | Level source; rebuilds `web/js/levels.js` and checks each level's par with the solver |
| `tools/generate.mjs` | Random level generator (no longer used; overwrites `web/js/levels.js`) |

### Level format

```js
{
  name: "Level 1",
  par: 5,                         // optimal move count
  nodes: [[x, y], ...],           // station grid positions
  edges: [[a, b, color], ...],    // track between stations a and b
  cars: [[node, color], ...],     // starting cars
  target: { car: 0, node: 7 }     // cars[0] must reach station 7
}
```

Colors are indices into `COLORS` in `web/js/engine.js`. An edge pair may appear twice with different colors (parallel tracks).

The current levels are placeholders for development and will be replaced by original Stoppo levels before launch. After editing `tools/build-levels.mjs`, rebuild with `node tools/build-levels.mjs`; it fails if any level's optimal solution differs from its par.
